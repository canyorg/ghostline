# Security policy

GhostLine is pre-alpha and **has not been audited**.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private vulnerability reporting
(*Security → Report a vulnerability*) on this repository.

Include affected version or commit, impact and reproduction steps. You will get a reply
within 7 days.

## Scope

Cryptographic design and implementation, the relay, the transport (Tor integration),
metadata leaks, the local store and the burn/delete logic.
Known, documented limitations (see README → *Known limitations*) are not vulnerabilities,
but ideas for improving them are welcome.
